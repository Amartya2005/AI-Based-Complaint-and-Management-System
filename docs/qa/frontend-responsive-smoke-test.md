# Responsive Frontend Smoke Checklist

Test at narrow mobile width, typical Android width, tablet width, and desktop.

- Login and registration forms remain readable without horizontal scrolling.
- Complaint submission controls fit the viewport and show validation clearly.
- Complaint tables have a usable narrow-screen presentation.
- Status badges and priority labels remain distinguishable without relying on color alone.
- Dialogs fit within the viewport and can be closed on touch devices.
- Loading, empty, and error states remain visible on small screens.
- Navigation can be operated by keyboard and touch.
- Long complaint titles and descriptions wrap without covering controls.
- Charts and analytics retain readable labels or provide a responsive alternative.

Record browser/device, viewport size, and reproduction steps for failures.
